# Echo 产品与技术设计

## 目标

打造一款离线优先的 Android「未来记忆工具」。用户写下一段当下的想法，Echo 在合适的未来时刻把它带回眼前；体验像翻开私人手账，而不是管理笔记。

## 首版边界

首版支持：写入记忆、可选单标签、独立到期通知、回顾反馈、低密度时间轴、归档、浅色/深色模式。数据只保存在设备本地；不包含账号、同步、搜索、统计、导出与小组件。

## 信息架构

底部导航包含「今日」「时光」「归档」：

- **今日**：显示当前日期、温和提示语、内联多行编辑器和保存操作；若存在到期记忆，则展示一张进入回顾的卡片。
- **回顾**：显示过去的日期、正文和「你还记得这句话吗？」；反馈为「仍然重要」「已经改变」「不再需要」。
- **时光**：按年和月分组的低密度卡片，展示正文、创建日期和下一次相遇文案。
- **归档**：显示不再需要的记忆，可重新激活。

## 视觉与交互

使用暖白背景（`#FAF8F5`）、石墨色文字、柔灰辅助文案和雾蓝绿色强调色；深色模式采用带暖感的深墨色。Compose Material 3 只承担可访问性和基础组件，不使用强烈的默认视觉。系统无衬线字体与充足行距服务中文阅读。

保存、反馈和页面进入仅使用短淡入/淡出与细微的状态过渡。没有弹跳、连续装饰动画、统计面板或高密度列表。

## 遗忘与回顾

领域层维护稳定度 `stabilityDays`、上次复习时间和下次回顾时间。记忆保留率为 `R(t) = exp(-t / S)`，但永不向用户展示公式或分数。

初始稳定度为 3 天。算法查找第一个使保留率降至 0.56 的整天间隔，并设为下次回顾：约 2 天。回顾反馈调整稳定度：

- `仍然重要`：稳定度乘以 2.4，最长 180 天；下次回顾延后。
- `已经改变`：稳定度乘以 1.25，最长 90 天；保留联系但更快再次相遇。
- `不再需要`：进入归档，不再调度通知。
- 从归档重新激活：稳定度重置为 3 天，重新安排回顾。

WorkManager 为每条活跃记忆建立唯一的一次性任务。Android 可能为了省电而延后触发；这是可靠而非精确闹钟的选择。

## 架构

采用单 Activity + Clean Architecture：

```
presentation/   Compose 页面、组件、ViewModel、导航与主题
domain/         Memory 模型、仓储接口、遗忘算法、用例
data/           Room Entity/DAO/数据库、仓储实现、WorkManager 调度器
```

UI 只从 `Flow` 驱动的 ViewModel 状态读取数据；所有写入通过用例进入仓储。数据层将 Room 记录映射为领域 `Memory`，并在新增、反馈、归档与重新激活后同步更新唯一 WorkManager 请求。

## 数据模型

`Memory` 具备：`id`、`content`、`tag`、`createdAt`、`lastReviewedAt`、`stabilityDays`、`nextReviewAt`、`status`（active/archived）、`reviewCount`。内容不可为空；标签是可选短文本。时间存储为 UTC epoch 毫秒，展示时转换为本地时区。

## 错误与可访问性

空白内容禁用保存。数据库操作异常显示不打扰阅读的简短提示。通知权限拒绝时应用仍完整可用，今日页用轻量说明提示用户可在系统设置开启。所有图标有内容描述，正文满足可读字号与对比度，按钮有至少 48dp 触控区域。

## 验证

纯 Kotlin 单元测试覆盖遗忘算法和用例。Room DAO 测试覆盖时间排序与归档过滤。Compose 测试覆盖首页保存与回顾反馈。手动检查浅深色、空状态、通知权限拒绝和回顾后的时间轴更新。
