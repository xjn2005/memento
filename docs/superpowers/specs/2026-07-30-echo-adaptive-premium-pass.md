# Echo 自适应回顾与精品体验升级

## 目标

将 Echo 的回顾节奏从单一倍数的遗忘曲线升级为本地、可解释、低打扰的个人化稳定度模型；同步完成输入态、回顾确认、时间轴元信息、空状态与深色模式的精品化打磨。

## 自适应回顾模型

每条记忆维持稳定度、回顾次数、上次回顾时间和下次回顾时间。新记忆的初始稳定度设为 4.5 天，使第一次提醒为约 3 天。

回顾后的稳定度以当前稳定度、实际回顾间隔和回顾次数共同计算：

- `仍然重要`：基础倍率 2.2，加上最多 30% 的连续回顾奖励。
- `已经改变`：基础倍率 1.25，加上最多 10% 的连续回顾奖励。
- 逾期回顾降低本次奖励，但不会惩罚或缩短到少于 1 天。
- 以 0.56 作为下一次相遇阈值；时间间隔最短 1 天、最长 365 天。
- `不再需要`：归档并取消唯一 WorkManager 任务。

模型只用于产生温和的未来相遇节奏；UI 不展示分数、公式或“正确答案”。

## UI 状态与文案

- 首页输入有内容时，底部导航淡出并禁用，输入为空后恢复；保存不会改变底层数据行为。
- 记忆卡片使用相对时间文案：1 天为“明天，再读读这句话”；2–6 天为“约 N 天后，再读读这句话”；7 天以上为“约 N 周/月后，再读读这句话”。
- 回顾反馈后展示一个 700ms 的结果状态：重要为“这份心意，会在更远的未来再出现。”；改变为“改变也值得被好好记住。”；归档为“它会安静地留在归档里。”。
- 时间轴卡片展示可选标签、创建日期和“已回顾 N 次”；0 次不显示该行。
- 空时间轴和空归档提供简短、克制的说明；深色模式延续深海军蓝、冰蓝和低对比发光边线。

## 验证

扩展纯 Kotlin 遗忘算法测试以覆盖初始间隔、连续回顾奖励、逾期回顾、最大间隔及反馈差异。构建 Debug APK，安装到模拟器，检查首页输入态、三种回顾确认状态、时间轴信息和浅深色模式。
